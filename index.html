Registro de la práctica

Modifica las masas y el coeficiente de fricción, inicia el experimento y observa cómo cambian las gráficas.

El reporte CSV incluye parámetros, resultados teóricos y mediciones simuladas de tiempo, posición, velocidad y aceleración.

Nota física: el valor mostrado de tensión se calcula durante el movimiento; si el sistema permanece detenido, se informa la tensión de equilibrio.

Para un modelo de reposo se supone fricción estática máxima igual a μmg como aproximación, porque el simulador solo solicita un coeficiente de fricción.
